# mugdown 0.2.1

2026-10-21。

- 块操作按钮收紧为 40 像素，距正文 6 像素，正文最小边距增加到 60 像素，解决窄窗口时按钮超出左边界的问题。
- 顶部拉手改为纯图标：收起时为点阵和下箭头，悬停展开时为图钉和上箭头。
- 点击拉手或工具栏空白可固定。固定后拉手向上收起、不再占位；仅工具栏末端图钉可以解锁，重复点击空白不会解锁。
- 独立制作 16、20、24、32 像素的粗描边杯子，并提供 48、64 像素版本供高 DPI 标题栏使用。标题栏按屏幕缩放选择合适的图像。详细大图及平台图标中大于 32 像素的图像数据保留原样。
