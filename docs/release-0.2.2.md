# mugdown 0.2.2

2026-10-21。

单文档隐藏 tab 后，用户自然会抓住标题栏空白处拖动整个窗口；此前只有 tab 和文件名的文档拖动会触发合并，整窗移动没有接入合并判定。

现在可以抓标题栏空白处拖动整窗，到另一个 mugdown 窗口顶部，出现蓝色接收提示后松手合并。单文档仍隐藏 tab；多文档窗口会整体合并，保留顺序与活动文档。拖到正文或桌面只移动窗口，Esc 取消。

合并前先完成正文提交，再移动全部文档；未保存内容和撤销记录保留。目标窗口关闭时不会移除来源文档。文件名/tab 单独拖动和窗口菜单继续保留。

验证见 [记录](verification.md)。Windows 生产构建通过；macOS 已接入同一逻辑和系统鼠标状态读取，但仍需 Mac 构建及实测。
