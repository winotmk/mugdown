# mugdown v0.2.7

- 修复 Markdown 中混用 HTML 时可视化编辑器打开失败的问题，覆盖 README 的 HTML 页头、折叠区和编号列表中的快捷键标签。
- 独立 HTML 块使用浅底色、左边线和 `HTML` 标签。通过段落左侧的加号或类型菜单选择「插入 HTML 块」，输入源码后点击「应用」即可预览，也可以随时重新编辑。
- 预览会过滤脚本和事件属性；文档保存仍保留原始 HTML。README 补充了仓库各目录的用途。

**Windows x64**：下载便携 ZIP，解压后运行 `mugdown.exe`。升级时可将旧版的设置文件与个人预设复制到新目录。附件中的 `.sha256` 文件用于校验下载。
