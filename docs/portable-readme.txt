mugdown 0.2.8 · Windows x64 便携版

解压后运行 mugdown.exe。支持 Windows 10/11，需要 Microsoft Edge WebView2 Runtime（Windows 11 及大多数 Windows 10 电脑已具备）。无需安装 Node.js、Rust、Git 或 .NET。

Ctrl+N 新建；Ctrl+O 打开；Ctrl+S 保存；Ctrl+Shift+S 另存为。
Ctrl+F 查找；Ctrl+H 替换；Ctrl+/ 切换可视化与 Markdown 源码。
也可以直接将 Markdown 文件拖进程序。

只保留“可视化”和“MD”两种模式。格式栏默认隐藏：鼠标经过顶部中央的点阵小拉手时下滑展开，拉手变成图钉和上箭头，移开收起。点击拉手或工具栏空白固定，固定后拉手向上消失；点击工具栏最右侧图钉解锁并收起。查找和替换位于“编辑”菜单。

单文档隐藏 tab。多文档时可拖出 tab 拆为新窗口。拖回时，直接抓住标题栏空白处拖动整个窗口，到另一个 mugdown 窗口的任意位置，出现整窗蓝色接收提示后松手，即可合并；正文中间和底部也能接收。窗口内所有文档、未保存内容和撤销记录都会一起保留。拖到桌面只移动窗口，Esc 取消。文件名/tab 的单文档拖动和窗口菜单合并仍可使用。

粘贴图片时，将图片保存到文档旁的同名文件夹：日记.md → 日记/image-….png。移动文档时请同时携带图片文件夹；“另存为”会复制引用的本地图片。

新文档不生成头部信息。已有 YAML/TOML 头部原样保留，在 MD 模式编辑。不会根据头部展示封面、作者、日期或标签。

设置：点击调色板按钮，可切换简体中文/English。界面皮肤、正文排版、字号、宽度与自定义 CSS 只影响显示，不改变文档。语言与工具栏固定状态会自动记住，升级保留旧版外观设置。
设置默认保存在 mugdown.exe 同目录的 settings.json，调色板显示为 ./settings.json。开启“随系统目录保存”后，使用 %APPDATA%\com.winotmk.mugdown\settings.json；关闭则迁回程序旁。切换会携带当前设置，重启记住选择；系统模式下程序旁文件只记录位置选择。原位置文件保留。目录不可写会明确提示，不会自行切换位置。首次运行仍可自动迁移旧版 AppData 设置。升级到新文件夹时可一起复制程序旁的 settings.json。文档直接保存在你选择的位置。

Markdown 排版增加 Air、Book、Compact、Notebook，与原有 GitHub、Sakura、Modest 共七种。可在程序旁 presets 目录新增自己的 UTF-8 CSS 文件，点击调色板的“刷新预设”后选择。支持修改和删除后刷新，单文件上限 500 KB；新增文件名即预设名。“自定义 CSS”可继续叠加。升级时可同时复制自己的预设文件。

段落点阵把手支持拖动整段，蓝线提示插入位置，Ctrl+Z 撤销，Esc 取消。内部段落拖动不再出现“打开文档”提示；外部 Markdown 文件仍可拖入打开。

该版本不包含文章库、标签管理、Git、OSS 或任何登录功能。
macOS 使用同一项目源码构建，通用包覆盖 Apple Silicon 与 Intel；macOS 构建与实机验收需在 Mac 完成。

开源组件、皮肤与字体的许可证见 licenses 文件夹。
