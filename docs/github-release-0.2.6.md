这是 mugdown 在 GitHub 的首个公开发布。mugdown 是一个直接编辑本地 Markdown 文件的桌面工具，窗口没有侧栏，工具栏可悬停展开或固定。

**下载**：选择 `mugdown-0.2.6-windows-x64.zip`（约 2.49 MB），解压后运行 `mugdown.exe`。需要 Microsoft Edge WebView2 运行时。附件中的 `.sha256` 文件用于校验下载。

- 支持可视化和 MD 源码编辑、段落拖动、选区工具栏，以及多文档窗口拆分和合并。
- 可切换简体中文 / English、界面皮肤与正文排版。默认把设置保存在程序旁，也可切到系统目录。
- 0.2.6 修正块编辑菜单和颜色面板的透明底色问题；菜单、选区工具栏和滚动条随当前皮肤配色。

macOS 通用构建已配置，尚未实机验收，本次只提供 Windows x64 便携版。
