# mugdown 0.2.5

2026-10-21。

- 块按钮以首行文字的实际高度对齐，保留紧凑间距；空段落的加号改用粗线条 SVG 图标。
- 段落把手改为编辑器内指针拖动，避免 Windows 原生文件拖放接管。显示插入线，支持移动整段、撤销、Esc 取消和边缘滚动；外部文档仍可拖入打开。
- 顶部工具栏入口留白透明，拉手与正文底色一致，保留浅阴影。预设配色也会同步到编辑区域底色。
- 新增 Air、Book、Compact、Notebook 四种排版，原有三种保留。程序旁 `presets` 目录支持自行添加 CSS 并刷新，详见 [预设说明](presets.md)。
- 设置路径改为 `./settings.json`；调色板增加“随系统目录保存”开关，Windows 开启后使用 `%APPDATA%\com.winotmk.mugdown\settings.json`，关闭则迁回程序旁。切换携带当前设置，重启保持选择。macOS 显示对应的 `~/Library/Application Support/...` 路径。

使用系统目录时，程序旁的设置文件只记录位置选择；实际外观设置写入系统目录。切回程序旁后，原系统文件保留。切换失败保持原选择并提示原因。默认仍使用程序旁保存。
