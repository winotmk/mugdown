# mugdown 0.2.0

2026-10-21。

- 编辑模式精简为“可视化 / MD”，移除独立预览模式。
- 格式工具栏默认收起。顶部中央的“编辑工具”拉手带点阵和箭头，悬停下滑展开、移开收起；点击拉手或图钉固定，再点取消固定。悬停展开时正文位置不变。
- 移除顶部“查找”菜单，编辑菜单和快捷键仍可查找替换。
- 外观设置增加简体中文 / English 切换，覆盖菜单、对话框、选区工具栏、段落菜单与提示。语言文件独立，添加语言只需复制 JSON、翻译值并重新构建，详见 [语言配置](i18n.md)。
- 图标改为更高、更圆润的奶油色空杯子，Windows 和 macOS 图标同步更新。
- 语言与工具栏固定状态自动保存；旧配置保留原有皮肤、CSS、字号与宽度。

单文档隐藏 tab、文档拖入、拆分合并窗口、段落块操作、选区浮动格式栏、图片保存到文档旁等能力保留。
