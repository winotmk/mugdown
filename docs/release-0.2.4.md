# mugdown 0.2.4

2026-10-21。

Windows 设置默认保存在 `mugdown.exe` 同目录的 `settings.json`，首次启动即创建。调色板底部显示实际路径，可以选中复制。移动整个程序文件夹即可携带皮肤、排版、CSS、语言和工具栏固定状态。

如果同目录还没有配置，会自动复制旧版 AppData 设置，保留旧文件；已有同目录配置优先。升级到新的文件夹时，请同时复制自己的 `settings.json`。目录不可写时明确提示原因与路径，不改存回 AppData。配置损坏时提示错误，并保留原文件供修正。

macOS 对应配置位于 `.app` 旁的 `mugdown.settings.json`，避免修改签名应用包；该路径逻辑通过测试，仍需在 Mac 构建和实测。

重新打包便携目录时只收录程序、说明和许可证，排除本地设置文件，并保留目录里的个人配置。
